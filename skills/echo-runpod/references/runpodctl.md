# runpodctl

Companion CLI. Useful on Hammer for humans. Echo operators should prefer official MCP/REST through this pack so policy, Vault, and receipts stay in the path.

Typical:

```text
runpodctl get pod
runpodctl stop pod <id>
runpodctl remove pod <id>
```

Auth is local to the CLI config. Do not scrape or commit that config.
